# TaskFlow — Professional To-Do App

A clean, industry-style task manager built with HTML, CSS, and vanilla JavaScript.

## Features

- Add, edit, delete, and complete tasks
- Priority levels: Low, Medium, High, Emergency
- Emergency tasks highlighted with urgency indicator
- Deadline tracking with overdue / today detection
- Search and filter (All / Active / Completed / Emergency)
- Progress stats and progress bar
- Local storage persistence across refreshes
- Smooth animations and responsive layout

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid, animations)
- JavaScript (ES6 classes, arrays, Date, localStorage, DOM)

## Usage

Open `index.html` in any browser. No build step required.
